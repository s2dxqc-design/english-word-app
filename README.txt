My English Words Ver.2

更新方法
1. GitHubのRepositoryを開く
2. index.html、manifest.webmanifest、sw.jsを新しいファイルで置き換える
3. sample_words.csvはサンプルなので任意
4. Commit changesを押す
5. GitHub Pagesの反映を数分待つ
6. iPhoneでページを再読み込みする

追加機能
・日ごとの学習履歴
・今日の問題数、正答率、学習時間
・苦手単語一覧
・「苦手だけ」復習モード
・苦手単語は3回連続正解で卒業
・Ver.1の単語と回答履歴を可能な範囲で引き継ぎ

音声について
iPhoneのWeb音声読み上げはマナーモードの影響を受ける場合があります。WebアプリからiPhoneの消音スイッチを強制解除することはできません。音が出ない場合は左側面の消音スイッチを解除し、音量を上げてください。
